# The Veteran File — VA Production Readiness Build

Adds:
- Privacy disclosure for Google Analytics and resource searches
- Accessibility commitment language without claiming full Section 508 certification
- Skip-to-content link
- Keyboard-visible focus states
- 44px minimum touch targets
- Reduced-motion support
- Clearer ZIP search help text
- Official VA locator fallback for zero-result searches
- Existing GA4, logo, mobile quick navigation, and `/api/facilities` route preserved

Important:
Before answering “Yes” to a formal Section 508 compliance certification, complete an accessibility review/testing process. This build improves accessibility but does not itself certify full compliance.
