# The Veteran File Resource Finder

A plug-and-play static website for The Veteran File.

## Fastest deployment with GitHub + Vercel

1. Open your GitHub repository.
2. Choose **Add file → Upload files**.
3. Drag **everything inside this folder** into the upload area. Do not upload the outer folder itself.
4. Commit the files to the `main` branch.
5. In Vercel, choose **Add New → Project** and import the GitHub repository.
6. Vercel should recognize this as a static site. No build command is required.
7. Click **Deploy**.

## Local preview

You can double-click `index.html` to preview the site in a browser. For the best test, use a small local server such as VS Code Live Server.

## Main files

- `index.html` — page structure and links
- `styles.css` — design and mobile layout
- `script.js` — ZIP saving, menu, and "Where do I start?" helper
- `assets/logo.png` — The Veteran File logo

## Important

The website is independent and not affiliated with the U.S. Department of Veterans Affairs. Official resource links should be rechecked periodically because government URLs can change.
